Kartenkacheln

Die Hintergrundkarte wird zur Laufzeit von OpenStreetMap geladen und steht unter der Open Database License (ODbL) 1.0. Die Kacheln werden nicht im Repository gespeichert und nicht dauerhaft zwischengespeichert; die Nutzung erfolgt im Rahmen der Tile Usage Policy der OpenStreetMap Foundation.

Ohne Internetverbindung bleibt der Kartenhintergrund leer. Planung, Stempelverwaltung und GPX-Export funktionieren weiterhin, weil sie vollständig lokal berechnet werden.

Wegführung und Parkplätze

Die Route wird entlang echter Wanderwege berechnet. Dafür ruft der Browser, sobald eine Tour berechnet wird, den öffentlichen Dienst BRouter mit dem Profil hiking-beta auf. Die Software steht unter der MIT-Lizenz; die Wegedaten stammen aus OpenStreetMap und unterliegen der ODbL. Es wird eine Anfrage pro Tag gestellt.

Wanderparkplätze werden aus OpenStreetMap geladen, über die Overpass-API, und zwar ausschließlich nach einem Klick auf „Parkplätze suchen“. Es sind keine Parkplatzdaten im Repository enthalten. „Parkplatz“ heißt dort „jemand hat eine Fläche eingetragen“, nicht „amtlicher Wanderparkplatz“.

Ohne Internetverbindung entfällt beides: Die Tour bleibt als Luftlinien-Schätzung stehen, und die Oberfläche sagt das. Es wird keine gerade Linie als Wanderweg ausgegeben.

Zum Seitenanfang

Die Anwendung erhebt keine Telemetrie. Es werden nur Daten an Dritte übertragen, die für die Anzeige der Karte nötig sind: Anfragen an den Kachel-Server. Ein optionaler Routing-Dienst wird ausschließlich dann kontaktiert, wenn er in der Konfiguration eingetragen wurde und eine Tour berechnet wird.
